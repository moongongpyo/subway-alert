# 결과 화면과 단건 리포트 · 2026-09-19

현재 흐름은 URL → 준비 → 사용자 입력·실행 → 결과 확인 → 같은 도구의 다음 실험 → 단건 리포트다. 다른 서비스 검색, 추천, 대안 재체험, 다중 실행 비교 리포트, 최종 서비스 선택은 제공하지 않는다. 이전 데이터는 삭제하지 않으며 옛 대안 실행 요청은 410으로 종료한다.

## 화면 설계 계약

결과 분석 호출 한 번으로 `view`와 다음 실험 카드를 생성한다. 별도 설계 모델이나 무한 품질 재시도는 없다. 기존 준비·분석·Nosana/OpenAI fallback 예산을 그대로 적용한다.

- 질문: 선택한 실험의 확인 조건 → 사용자 목적 → 검증된 기능 순서로 서버가 맥락을 구성한다. 최초 목적 입력은 필수가 아니다.
- 근거: 현재 응답, 현재 입력, 같은 도구의 이전 응답·입력에 대한 JSON Pointer와 통계 연산을 명시한다. 모델이 계산한 값을 HTML에 복사하지 않는다.
- 표현: 모델은 근거에 맞는 시계열, 후보 목록, 미디어, 같은 도구의 이전 측정값 또는 단순 응답 구성을 선택한다. 제목, 비교 필드, 단위 경로, 이유, 미확인 사항도 설계에 포함한다.
- 품질: 근거 경로의 존재, 수치 계열과 축의 길이·순서, 단위 일관성, 선택한 표현의 컴포넌트 존재, 현재 응답 근거를 검사한다. 빈약하거나 잘못 연결된 구성은 `quality.status=limited`로 기록하고 한계를 화면에 표시한다. `grounded`는 구조와 값 연결의 검증 결과이며 주관적인 유용성이나 목적 충족을 보증하지 않는다.

새 뷰의 HTML/CSS/SVG는 이 계약에서 서버가 구성한다. 모델의 임의 HTML/CSS는 새 뷰에 실행하거나 삽입하지 않는다. 과거 HTML 결과는 계속 열 수 있다. 응답과 모델의 모든 문자열은 이스케이프한다.

## 데이터와 상호작용

프로파일은 선택한 필드의 저장 응답 전체 행을 순회한다. 반환 개수, 결측, 최소·최대·평균·합계, 분위수, 처음·마지막 값의 차이, 범주 빈도를 계산한다. 컨텍스트에는 최대 16개 배열·12개 열, 24개 스칼라를 전달하며 구조 생략 여부를 명시한다. 표본은 처음 5개 대신 위치를 분산해 최대 5개를 제공한다. 원격 전체 데이터 집합을 분석했다고 주장하지 않는다.

- 시계열: 실제 수치/시간 간격의 축, 결측 구간 단절, 실제 단위, 계열 켜기/끄기, 구간 탐색. 긴 계열은 구간별 극값·결측을 보존한 표시용 축약을 명시한다. 통계는 축약 전 전체 반환 값으로 계산한다. 단위가 다른 계열은 한 축에 겹치지 않는다.
- 후보 목록: 모델이 고른 최대 6개 스칼라 열과 최대 500개 행, 표시 범위 내 검색. 중첩 객체를 펼쳐 거대한 셀로 만들지 않는다. 순서는 원본이며 자동 순위가 아니다.
- 미디어: 소유권 검사를 거친 보관된 PNG/JPEG/GIF/WebP의 원본·결과 나란히 보기와 공통 배율 확대. 외부 URL 이미지는 링크로 표시하고 임의 프록시 요청을 만들지 않는다. 이미지 바이트를 보지 않은 모델은 경계 품질을 판정하지 않는다.
- 이전 측정: 같은 도구의 이전 실행만 참조한다. 입력·버전·환경 변경을 명시하며 단위나 도구가 다르면 차이 계산을 보류한다. 변경된 조건의 인과 효과나 도구 우열을 주장하지 않는다.

결과 iframe은 `script-src 'none'`과 스크립트 없는 sandbox를 유지한다. 신뢰된 상위 앱 코드가 서버가 만든 검색·구간·확대 컨트롤만 연결한다. 이 상호작용은 모델이나 외부 API를 호출하지 않는다.

## 리포트

단건 리포트는 실행 ID 하나만 받으며, 여러 ID와 추가 모델 해석 요청을 거절한다. 해당 실행 시점의 목적·입력·출력·판정·피드백·측정 범위·비용의 확정 여부·같은 버전의 레시피를 저장한다. 최신 목적이나 다른 실행을 섞지 않는다. Markdown만 지원하고 생성과 다운로드에는 모델 호출이 없다.

화면 설계나 주관적 품질을 자동 점수화하지 않는다. PDF/Word, 지도, 임의 스크립트, 외부 이미지 다운로드, 서비스 간 비교는 현재 범위에 포함하지 않는다.
